# Propuesta: gestión ganadera sin señal

Página estática con la propuesta de un proyecto universitario: una aplicación para el pequeño ganadero de doble propósito que funciona sin internet, con la línea de tiempo de cada animal y la lógica de negocio transaccional en PostgreSQL (SQL primero).

En línea: https://srjaniot.github.io/propuesta-ganadero/

## Publicar
Desde esta carpeta: `sh scripts/publicar-pages.sh`. Crea el repo público si no existe, sube `main` y activa GitHub Pages sobre `main` en la raíz.
